# Changelog

## v1.0.0

### Added

- Multi-source AI intelligence collection pipeline
- GitHub trend collection
- Hacker News collection
- Hugging Face model discovery
- Data normalization and duplicate filtering
- Trend scoring system
- LLM analysis pipeline
- SQLite persistence layer
- Feishu bot notification workflow
- CLI health check command
- Automated test suite
- GitHub Actions CI workflow
- Local verification scripts and Makefile commands

### Usage

```bash
make check
make test
make run
```

### Current Scope

The first stable version focuses on reliable AI intelligence collection and Feishu daily reporting.

Future expansion:

- Product Hunt collector
- arXiv paper collector
- Dashboard visualization
- Advanced business opportunity scoring
