# AI Intelligence Radar v1.0.0

## Release Overview

First production-ready version of AI Intelligence Radar.

## Completed Features

- Multi-source AI information collection
- GitHub project tracking
- Hacker News trend tracking
- HuggingFace model tracking
- Data normalization and duplicate filtering
- Trend scoring engine
- LLM-based analysis pipeline
- SQLite historical storage
- Feishu daily report notification
- CLI health check
- Automated test suite
- GitHub Actions CI
- Docker deployment support

## Run

```bash
make check
make test
make run
```
